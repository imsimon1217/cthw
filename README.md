# 仁濟醫院趙曾學韞小學網站

沿用已確認的首頁設計，分類頁及老師後台改為可持續新增內容的網站。無需建置程序；前台使用 HTML / CSS / JavaScript，正式後台使用 PHP 與 SQLite（亦支援 MySQL）。

## 這一版的內容

- 44 個分類、29 篇文章／相簿，包括 7 組多圖相簿。
- 20 個單篇分類入口直接開全文／相簿，新增第二篇已發布內容時自動恢復列表；14 個未有實質內容的分類暫從前台隱藏，後台保留可恢復。
- 七種分類版面：專題導覽、家校社群、消息刊物、相簿展覽、文件資料、入學指南、聯絡資訊。
- 九種可任意組合的內容區塊：文字、單圖、圖文專題、多圖相簿、提示、清單、步驟、文件連結、常見問題。
- 37 張由學校 Word 檔提取的圖片、原有校園照片及 3 張明確標示的主題插畫。
- 分類搜尋、子分類篩選、載入更多、草稿／發布、日期排序及置頂、相片放大瀏覽。
- 分類及文章共用同一份內容模型；老師可增加分類、文章、相簿、相片和文字，不受固定版面欄位數量限制。

## 本機預覽

靜態預覽可用 `python3 -m http.server 4173 --bind 127.0.0.1`，再開啟首頁或 `admin.html`。

靜態示範帳戶：`teacher` / `ych2026`。靜態模式的修改與相片只存於同一瀏覽器、同一網址來源的 IndexedDB；不是公開伺服器更新。舊 localStorage 資料會與上一版基準比較，保留實際修改後載入新版；原有快照不會被刪除。PDF 上載需要 PHP 伺服器，靜態模式可填寫文件網址。

要測試真正伺服器流程，可在具備 PHP 的環境執行 `php -S 127.0.0.1:4175 -t .`。只供本機測試，不可將開發伺服器用於正式上線。

## 老師日常操作

1. 登入後選擇左方分類；名稱對應前台。
2. 按「新增文章」或「新增相簿」，填標題、摘要及封面。
3. 加入所需區塊；相簿可一次上載多張圖片，每張都有說明及替代文字，箭嘴可排序。
4. 先用草稿及預覽檢查，選「已發布」再按「儲存所有修改」。
5. 按「分類版面與介紹」可改分類介紹、封面、顯示方式，或隱藏分類。
6. 「首頁及聯絡設定」提供共用聯絡資料及內容備份。正式伺服器另須備份上載檔案與資料庫。

每個上載圖片／PDF 限 6 MB。篇數與相片張數沒有程式固定上限，實際容量受瀏覽器、伺服器及請求大小限制。草稿及隱藏分類（連子分類）的內容不會由匿名內容 API 回傳。

詳見 [老師操作指南](docs/teacher-guide.md)、[內容來源與編輯說明](docs/content-sources.md)。

## 學校 IT 部署要求

GitHub 供學校協調審閱；學校確認後才製作交付包，由校方自行部署。本輪不會部署至學校伺服器。

- PHP 8.2+，啟用 PDO、pdo_sqlite（或 pdo_mysql）、session、fileinfo。
- 複製 `api/config.example.php` 為 `api/config.php`，設定資料庫及正式帳戶。**不得沿用示範帳密或 salt 上線。**
- 建議把 SQLite 資料庫放在網站根目錄之外，並在 config 指定絕對路徑；PHP 必須能寫入該目錄。
- 若使用預設 `data/` 路徑，Apache 必須啟用隨附的 `data/.htaccess`；Nginx 必須另行拒絕存取 `.sqlite`、`.sqlite-*` 等資料庫檔案。上線前實測不可下載資料庫。
- 建立並允許 PHP 寫入 `assets/uploads/`；該目錄只應提供靜態檔案，不可執行腳本。
- HTTPS、定期資料庫／uploads 備份、合理的 PHP `upload_max_filesize`（至少 6M）、`post_max_size`（建議 16M 起，按內容量調整）及可寫入的上載／session 臨時目錄。
- GitHub Pages 只支援靜態展示，**不能提供全校共用的 PHP 後台**。
- 若學校已有舊版內容資料庫，上線前先備份、在測試環境合併內容；不要刪除或直接覆寫老師已更新的資料。
