# 仁濟醫院趙曾學韞小學網站重設概念

這是一個可直接預覽及部署到 GitHub Pages 的靜態網站版本。

## 檔案

- `index.html`：首頁內容及資訊架構
- `styles.css`：桌面與手機版樣式
- `script.js`：手機選單及頁首互動
- `assets/school-logo.png`：由現有網站保存的校徽資產
- `assets/campus-learning-hero.png`：為新版網站生成的校園學習 hero 圖片

## 內容來源與備註

新版保留現有網站可見的主要導覽結構：關於趙小、學與教、多元體驗、校園導賞團、eClass、Facebook，以及最新消息、學校資訊、活動花絮、加入趙小、招標、課程發展、語文學習、STEAM、個人成長、其他學習經歷、課外活動、走出課室及星級導師等內容分類。

地址、電話、電郵、校長姓名及最新通告等正式資料，建議由校方確認後再加入。
