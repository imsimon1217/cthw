# 老師內容工作室操作指南

## 新增消息或通告

在左方選「學校生活 → 最新消息」，按「新增文章」。填寫標題及摘要，可上載封面。用文字、圖片、文件連結或常見問題區塊組成全文。文件連結可直接上載 PDF（正式 PHP 後台）。

新增項目預設為草稿。按預覽檢查後，把發布狀態改為「已發布」，再按「儲存所有修改」。前台消息清單會自動增加，不需修改網頁程式。

發布日期會用作新到舊排序；置頂文章優先。同日期或未填日期的項目依人工次序排列。列表箭嘴可調整人工次序，但不會蓋過置頂及日期排序。

## 新增多張相片

選「活動相片」或「校園環境」，按「新增相簿」。在多圖相簿區塊一次選取多個 JPG、PNG 或 WebP 檔案；每張少於 6 MB。完成後可填相片說明、替代文字，並用箭嘴排序。

可以繼續加入另一組相簿、文字說明或其他內容區塊，不限於一張圖片。建議大批活動相片按主題或日期分成多個相簿，方便家長閱讀。相簿封面可獨立選擇；若未指定，列表會使用第一張相簿圖片。

「移除」先作用於編輯稿；尚未儲存時可按「復原移除」。正式上載檔案不會因移除引用而自動從伺服器刪除，避免其他文章引用失效；學校 IT 可定期整理未使用檔案。

## 修改分類頁

「分類入口」可選擇「只有一篇時直接開全文／相簿」：家長按分類名稱便直接閱讀，不必經過簡介中間頁。要更新這些頁面的文字或相片，請編輯下方對應的文章／相簿。新增第二篇並發布後，前台會自動恢復分類列表，無須更改導航連結；草稿不計入。入學申請、趙小一家等有實質導覽內容的主頁保留「完整分類導覽頁」。

尚未有實質內容的 14 個分類已從前台隱藏，後台分類和介紹仍然保留。補充正式內容後，可勾選「在網站顯示此分類」恢復，毋須重新建立。

分類封面、標題區附加圖片及正文圖文專題均可自行更換。打開「分類版面與介紹」後，在「標題區附加圖片」可一次上載多張相片，或用箭嘴重新排序。圖片沒有固定張數限制。

若圖片打橫或倒轉，在該圖片旁的「圖片方向」選擇順時針 90°、旋轉 180° 或逆時針 90°，再儲存。設定會同時用於前台圖片、相簿及放大檢視；原始圖片檔不會被改寫。上載另一張新圖後方向會重設，請按新圖需要調整。

「圖文專題」區塊包含圖片、段落、按鈕文字及連結，可用來建立像家校合作與入學指南中的左右圖文內容。各部分都可以修改或繼續新增。

首頁大圖在「首頁及聯絡設定 → 首頁主視覺」更換；分類封面則在對應分類修改。移除分類封面後不會自動借用上層分類或首頁圖片。

選分類後打開「分類版面與介紹」。可修改標題、簡介、封面，以及任意數量的內容區塊。下方的文章清單會自動列出此分類及子分類的已發布內容。

顯示方式建議：

- 消息刊物：通告、活動消息、學習故事。
- 相簿展覽：活動照片、作品展、校園環境。
- 文件資料：校曆、計劃報告、行政文件。
- 專題導覽：學科介紹、家校合作及學校背景。
- 入學指南：分步資訊、所需文件和常見問題。
- 聯絡資訊：共用校務處資料配合詳細說明。

新增分類預設隱藏。確認內容與上層分類後，勾選「在網站顯示此分類」並儲存。隱藏父分類亦會一併隱藏其子分類內容。

## 儲存、預覽與備份

所有編輯集中由右上方「儲存所有修改」一次儲存。離開前應確認顯示「已儲存」。預覽不代表已儲存或發布。上載過程中請等候完成再操作。

在「首頁及聯絡設定」可下載 JSON 內容備份；它包含文章、分類和相片路徑，但正式伺服器圖片檔案須另行備份。匯入會取代目前編輯稿，先下載備份再操作。

靜態示範的內容只在自己的瀏覽器保存，不能讓其他電腦的訪客看到。校方部署 PHP 後台後，老師照相同操作儲存，公開內容才會更新到全校網站。示範模式不支援 PDF 檔案上載，可用文件網址測試。

日常新增文章、相簿、圖片、文件及分類毋須找開發者修改程式；伺服器、帳戶設定、容量與備份仍由學校 IT 維護。
